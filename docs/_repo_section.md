# Project Repository

The complete source code, the corpus generator, the trained models, the results files and the console are available at:

**https://github.com/BhavyeNijhawan/svarkavach**

`src/swarkavach/` holds the corpus grammar, the four branches, the fusion layer and the runner; `server/` the console; `data/results/` the JSON files every table and figure in this report was drawn from; `docs/` this report and its figure sources. The console is started with `python -m swarkavach.cli serve` and opens at http://127.0.0.1:7860.
